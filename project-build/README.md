# Digital Dental Lab v2 - لابراتوار دندانپزشکی دیجیتال

## خلاصه پروژه
سیستم مدیریت پیشرفته کلینیک دندانپزشکی دیجیتال با Angular - دارای گالری کارهای انجام شده، خدمات تخصصی، بلاگ آموزشی، پنل چندزبانه و رابط کاربری مدرن

## معماری سیستم
Angular 20 SPA با معماری کامپوننت‌محور، پشتیبانی از i18n (فارسی/انگلیسی)، routing پیشرفته، سرویس‌های ماژولار، state management و رابط کاربری ریسپانسیو با طراحی مدرن

## تاریخچه تغییرات
- **2.0.0** - آپدیت کامل پروژه - افزودن routing پیشرفته، سیستم چندزبانه کامل، سرویس ترجمه، فایل‌های پیکربندی و مستندات جامع
- **1.0.0** - ایجاد پروژه اولیه با CLI
